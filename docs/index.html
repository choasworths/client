Overview

What is Leaf Client?

Leaf Client is a free Minecraft client for Fabric, Forge and NeoForge. It ships with 35+ built-in mods, HUD elements, quality-of-life mechanics and performance mods, all configurable in game or through the launcher.

Leaf Client is currently in beta. Features are still being built and improved. Join the Discord to follow updates and report issues.
  • 35+ built-in mods, each one can be toggled and configured
  • A launcher with profile management for Windows, macOS and Linux
  • Minecraft 1.8.9, 1.21 through 1.21.11 and 26.1.2 on Fabric, Forge and NeoForge
  • Sodium and Lithium installed by default for better performance
  • Discord Rich Presence
  • Cosmetics (wings, crowns, particles)
  • Server-side feature control through a plugin messaging channel
Setup

Getting started

It takes about a minute. All you need is Java and a Minecraft: Java Edition account.

  1. Download the launcher

    Go to the download page and get the installer for your platform. Run it, no extra setup needed.

  2. Sign in with Microsoft

    The launcher signs you in with Microsoft OAuth. Click Sign In, finish the browser flow, and your account is saved for next time.

  3. Pick a Minecraft version

    Choose a version in the version selector. Leaf Client supports 1.8.9, 1.21 through 1.21.11 and 26.1.2 on Fabric, Forge and NeoForge. On Fabric, Sodium and Lithium are installed automatically.

  4. Press Launch

    The first launch downloads the files it needs, then opens the game. After that, launches start right away.

  5. Open the mod menu in game

    Press Right Shift to open the Leaf Client mod menu. Turn mods on or off and change their settings there.

For server operators

Server-side feature control

Leaf Client listens on a plugin messaging channel that lets servers disable specific client features while a player is connected. Use it if your server wants to restrict some of the supported mods.

This works per session. Features come back when the player disconnects and reconnects, so servers should send the disable payload every time a player joins.

How it works

Once a player has joined your server and their client has registered the channel, your plugin sends a plugin message on the leafclient:control channel. The payload is a UTF-8 encoded JSON object listing the mod IDs you want to disable.

Leaf Client receives the packet and disables every listed mod for the rest of the session. The player's own settings are not changed, and everything goes back to normal on reconnect. Players cannot turn server-disabled features back on while they stay connected.

This uses the standard Minecraft plugin messaging protocol, so it works on every major server platform: Bukkit, Spigot, Paper, Purpur, Velocity, BungeeCord, Sponge, Fabric server-side and more. Vanilla clients that don't register the channel ignore the packet.

Payload format

Send a single JSON object with a disabled array containing the mod IDs to restrict. One packet can disable one mod or several.

JSON, leafclient:control payload 
{ "disabled": ["freelook", "fullbright"] }
Mod IDWhat it disables
freelookThird-person orbit camera
fullbrightMaximum brightness override
minimapReal-time minimap HUD
zoomScroll-wheel zoom (C key)

Detection: is a player running Leaf Client?

Leaf Client registers the leafclient:control and leafclient:disable channels using the standard Minecraft channel registration handshake. On 1.8.9 the registration arrives just after the player joins, so in PlayerJoinEvent the channel is not listed yet. Check the registered channels on join, and also listen for PlayerRegisterChannelEvent to catch players whose registration arrives later.

Java, Paper, detect Leaf Client 
@EventHandler
public void onJoin(PlayerJoinEvent e) {
    if (e.getPlayer().getListeningPluginChannels().contains("leafclient:control")) {
        // player is running Leaf Client
    }
}

@EventHandler
public void onRegister(PlayerRegisterChannelEvent e) {
    if (e.getChannel().equals("leafclient:control") && e.getPlayer().isOnline()) {
        // player is running Leaf Client and registered after joining
    }
}

persistenceSession only, resets on disconnect
safe to send to all playersYes, vanilla clients ignore it
This channel only affects Leaf Client. Vanilla clients and other modpacks ignore the packet, so it is safe to send to every player without checking first. Bukkit, Spigot and Paper only deliver it once the player has registered the channel, which 1.8.9 does just after joining.

plugin.yml declaration

Your Bukkit, Spigot or Paper plugin must declare the outgoing channel in plugin.yml before it can send plugin messages.

YAML, plugin.yml 
name: MyPlugin
version: 1.0.0
main: com.example.myplugin.MyPlugin
api-version: 1.20

channels:
  - leafclient:control

Full working example, PaperMC plugin

A complete, minimal PaperMC plugin that disables Freelook for every Leaf Client player as soon as their client has registered the channel. Use it as a starting point and add or remove mod IDs in the JSON array.

Java, PaperMC plugin (full example) 
package com.example.leafcontrol;

import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerJoinEvent;
import org.bukkit.event.player.PlayerRegisterChannelEvent;
import org.bukkit.plugin.java.JavaPlugin;

import java.nio.charset.StandardCharsets;

public class LeafControlPlugin extends JavaPlugin implements Listener {

    private static final String CHANNEL = "leafclient:control";

    /** JSON payload, add or remove mod IDs as needed */
    private static final String PAYLOAD =
        "{\"disabled\":[\"freelook\"]}";

    @Override
    public void onEnable() {
        getServer().getMessenger().registerOutgoingPluginChannel(this, CHANNEL);
        getServer().getPluginManager().registerEvents(this, this);
        getLogger().info("LeafControl enabled, freelook will be disabled for all players.");
    }

    @Override
    public void onDisable() {
        getServer().getMessenger().unregisterOutgoingPluginChannel(this, CHANNEL);
    }

    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        if (event.getPlayer().getListeningPluginChannels().contains(CHANNEL)) send(event.getPlayer());
    }

    /** 1.8.9 registers the channel just after the join */
    @EventHandler
    public void onRegister(PlayerRegisterChannelEvent event) {
        if (CHANNEL.equals(event.getChannel()) && event.getPlayer().isOnline()) send(event.getPlayer());
    }

    private void send(Player player) {
        player.sendPluginMessage(this, CHANNEL, PAYLOAD.getBytes(StandardCharsets.UTF_8));
    }
}
To disable several mods at once, extend the JSON array: {"disabled":["freelook","fullbright"]}. One packet covers all of them.
Freelook control

Disabling Freelook on your server

If your server wants to stop players from using Freelook (the third-person camera), disable it server-side with one small plugin message sent once the player's client has registered the channel.

Freelook is disabled per session. It comes back when the player disconnects and reconnects, so send the disable packet every time a player joins.

Bukkit / Spigot / Paper / Purpur

Java, Bukkit plugin 
@Override
public void onEnable() {
    JavaPlugin plugin = this;
    getServer().getMessenger().registerOutgoingPluginChannel(plugin, "leafclient:disable");

    getServer().getPluginManager().registerEvents(new Listener() {
        @EventHandler
        public void onJoin(PlayerJoinEvent e) {
            if (e.getPlayer().getListeningPluginChannels().contains("leafclient:disable")) send(e.getPlayer());
        }

        @EventHandler
        public void onRegister(PlayerRegisterChannelEvent e) {
            if (e.getChannel().equals("leafclient:disable") && e.getPlayer().isOnline()) send(e.getPlayer());
        }

        private void send(Player player) {
            byte[] payload = "freelook".getBytes(StandardCharsets.UTF_8);
            player.sendPluginMessage(plugin, "leafclient:disable", payload);
        }
    }, this);
}

Velocity

Java, Velocity plugin 
@Subscribe
public void onPostLogin(PostLoginEvent event) {
    ChannelIdentifier channel = MinecraftChannelIdentifier.from("leafclient:disable");
    server.getChannelRegistrar().register(channel);

    event.getPlayer().sendPluginMessage(channel, payload);
}

@Override
public void onEnable() {
    getProxy().registerChannel("leafclient:disable");

    getProxy().getPluginManager().registerListener(this, new Listener() {
        @EventHandler

            e.getPlayer().sendData("leafclient:disable", payload);
        }
    });
}

FullBright control

Disabling FullBright on your server

FullBright bypasses Minecraft's lighting engine so the player always sees at full brightness. If your server has gameplay that depends on darkness (horror maps, cave exploration and so on), disable it server-side once the player's client has registered the channel.

FullBright is disabled per session. It comes back when the player disconnects and reconnects, so send the disable packet every time a player joins.
