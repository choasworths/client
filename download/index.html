Install guide

Before you install

Axquen Client runs in its own folder, separate from any existing Minecraft install. It downloads Fabric, the Axquen mod and any mods you pick. Your .minecraft folder, saves and Microsoft account are not touched. If your system doesn't have a matching Java version, it is fetched on first launch.

Stuck? The Axquen Client Discord is the fastest way to get an answer.

Install on Windows
  1. Click Download above to download the Windows installer.
  2. Open the installer and follow the on-screen steps.
  3. Wait for it to finish installing.
  4. Launch Axquen Client from your desktop or Start Menu.
Install on macOS
  1. Get the matching .dmg above: Apple Silicon for M-series Macs, Intel for older ones.
  2. Open the disk image and drag Axquen Client to Applications.
  3. First launch only: right-click the app and choose Open to get past Gatekeeper (the build isn't Apple-notarised yet).
  4. Sign in, pick a version, launch.

A plain .zip is also published for each architecture if you prefer it over the disk image.

Install on Linux
  1. Download the Installer above.
  2. Run chmod +x AxquenClientSetup-1.11.0-linux-x64, then run it and follow the on-screen steps.
  3. It downloads the latest Axquen Client, creates desktop and app menu entries, and writes an uninstall.sh into the install folder.
  4. Prefer not to install anything? Get the portable .AppImage instead, chmod +x it and run it. It can live in any folder and has .NET bundled inside.
Install the mod JAR (no launcher)
  1. Pick your loader and Minecraft version above and download the JAR.
  2. Install the matching loader for that same Minecraft version: Fabric, Forge or NeoForge. On 1.8.9, Fabric means Legacy Fabric.
  3. Drop the JAR into your mods/ folder. On Fabric (1.21.x) also add Fabric API.
  4. Launch Minecraft through your usual launcher (Mojang, Prism, MultiMC and so on).
  5. On the title screen the mod asks you to sign in to your Axquen Client account, with Microsoft or with a username and password.

The standalone JAR is the same client mod that ships with the Axquen launcher. Cosmetics, friends and Axquen+ all work. The launcher adds version management, JVM tuning and auto-update on top.

System requirements
  • CPU: any 64-bit dual-core from 2015 or later.
  • RAM: 4 GB allocated for vanilla, 6 GB for moderate mods. Going past 8 GB rarely helps.
  • GPU: anything supporting OpenGL 4.6. Sodium handles low-end integrated GPUs well.
  • Disk: about 1.5 GB for the launcher and one Minecraft version, about 250 MB per extra version.
  • Network: needed for first launch and mod downloads. Day-to-day use works offline.
Frequently asked questions

Is Axquen Client free?

Yes. The launcher and the in-game client are free. Cosmetics and Axquen+ are optional and never affect gameplay balance.

Will I get banned for using it?

Axquen has no cheats, only quality-of-life features like the HUD, minimap, keystrokes and FPS mods. Servers can disable specific modules and Axquen respects that. Always check the server's rules.

Does it work with OptiFine shaders?

OptiFine itself isn't Fabric-compatible, but you can use the same shader packs through Iris (installable from the launcher's Shaders tab).

Can I move my Microsoft account between launchers?

Your Microsoft password never touches Axquen. Signing into Axquen and into any other launcher are separate OAuth sessions.

Why does my antivirus warn about the launcher?

Single-file .NET programs from small publishers sometimes get flagged by heuristics. Every release is signed with the same Ed25519 key, and updates that don't validate are refused.

Troubleshooting

The download finishes but the launcher won't open

You're probably running it from inside the ZIP. Extract the ZIP first, then run the program from the extracted folder.

"Java not found" or "JVM_DLL_NOT_FOUND"

Open Settings > Java and either point it at an installed JDK or click Download recommended JRE to fetch a Mojang runtime automatically.

Stuck at "Loading"

Usually a firewall blocking resources.download.minecraft.net, the Modrinth API or cdn.chaosworths.com. Check Open Logs for the host that fails.

The game crashes after the Mojang screen

Most often a leftover mod built for a different Minecraft version. Open the game logs window from the launch screen for a per-mod summary, then disable the bad one in Mods > Installed.
